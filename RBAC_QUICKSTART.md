# 🚀 RBAC Quick Start Guide - 5 Minutes

## Step 1: Run Migration (1 min)
Open in browser: http://localhost/auction_system/migrate_add_roles.php
Click "Run Migration" → See "✓ Migration complete!"

## Step 2: Test Admin (2 min)  
Login as first user → Go to /admin/dashboard.php → See metrics

## Step 3: Test Seller Workflow (2 min)
Create new account → Request seller → Admin approve → Access dashboard

---

## Three Roles

**Admin** - Manage sellers, users, moderate content
**Seller** - Create listings after approval  
**Buyer** - Browse and bid (default role)
